# research — 판결 엔진 평가

| 파일 | 내용 | 현재 상태 |
|---|---|---|
| `cases.csv` | 실제 갈등 사례 분석 표(유형·표현·심각도·재구성 요약) | **템플릿만 있음.** `EX-*` 3행은 AI 합성 예시이며 실제 사례가 아님 |
| `testset.json` | 엔진 평가용 사연 34건 + 판단 라벨 | **사연·라벨 모두 AI 합성.** 라벨은 `labeler: "draft"`(AI 초안), 사람 검수 전 |
| `run_eval.js` | `node research/run_eval.js` — 쟁점 정확도·과실 일치율·안전필터 정탐/미탐/오탐 | — |

## 데이터 출처 (정확한 현황)
- 이 폴더와 `app.html` PRESETS에 이번에 추가된 사연은 모두 **AI(Anthropic의 Claude)가 생성한 합성 데이터**다. 커뮤니티 게시글을 읽거나 옮겨서 만든 것이 아니다.
- 크롤링·스크래핑은 하지 않았다. 커뮤니티 원문은 이 저장소 어디에도 없다.
- 이름은 흔한 가명이고, 실명·닉네임·연락처·지역·직장·학교명은 없다.
- 판단 라벨(쟁점·과실 우세 쪽·안전필터 해당 여부)도 AI 초안이다. 사람이 검수해 `labeler`를 `"human"`으로 바꾸기 전까지는 참고값이다.

## 평가 수치를 읽을 때 주의
- 안전필터(SAFETY)와 쟁점 키워드 보강안은 **같은 AI가 같은 testset을 보고** 골랐다. 그래서 이 testset 기준 수치(예: 안전 정탐 9/9, 쟁점 100%)는 표본 내 성적이고 실제 입력에서의 성능을 과대평가한다.
- 일반화 성능을 보려면 키워드 선정에 쓰지 않은 사연(가능하면 사람이 새로 쓴 것)으로 따로 측정해야 한다.

## 앞으로 사람이 실제 사례를 정리할 때의 규칙
- 크롤링·스크래핑 금지. 사람이 직접 읽고 **유형만 정리**한다.
- 원문 문장을 옮기지 않는다. `재구성 사연`은 일반화해 새로 쓴 1~2문장 요약.
- `자주 나온 표현`은 일반 구어 표현 단위(예: 안읽씹, 단톡방, 손절)만, `|`로 구분.
- 실명·닉네임·연락처·지역·직장·학교명·게시글 URL/제목 저장 금지.
- 원문을 보며 쓰는 개인 메모는 `research/raw/` 또는 `*.local.*` 파일에 둔다 → `.gitignore`로 커밋 제외.
- 실제 사례 기반 행은 `id`를 `EX-*`가 아닌 번호(예: `C001`)로 쓰고, `출처유형`에 지식인/네이트판/더쿠/인스티즈 중 하나를 적는다.

## cases.csv 컬럼
- `출처유형`: 지식인 / 네이트판 / 더쿠 / 인스티즈 (AI 예시 행은 `예시`)
- `쟁점`: 기존 ISSUES id(time, contact, money, chores, space, care, tone, team) 또는 `NEW:이름`
- `심각도`: 일상 / 주의 / 게임불가(폭력·스토킹·협박·자해 등 → 안전필터 대상)
