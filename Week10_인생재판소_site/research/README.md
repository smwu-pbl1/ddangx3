# research — 실제 갈등 유형 기반 엔진 검증

| 파일 | 내용 | 누가 채우나 |
|---|---|---|
| `cases.csv` | 사례 분석 표(유형·표현·심각도·재구성 요약) | 사람(수동 수집) |
| `testset.json` | 엔진 평가용 창작 사연 + 사람 판단 라벨 | 초안 Claude, 검수 사람 |
| `run_eval.js` | `node research/run_eval.js` — 일치율·안전필터 정탐/미탐 출력 | — |

## 작성 규칙 (꼭 지키기)
- 크롤링·스크래핑 금지. 사례는 사람이 직접 읽고 **유형만 정리**한다.
- 원문 문장을 옮기지 않는다. `재구성 사연`은 내용을 일반화해 새로 쓴 1~2문장 요약.
- `자주 나온 표현`은 **일반 구어 표현 단위**(예: 안읽씹, 단톡방, 손절)만, `|`로 구분. 문장째 복사 금지.
- 실명·닉네임·연락처·지역·직장·학교명·게시글 URL/제목 저장 금지.
- 원문을 보며 쓰는 개인 메모는 `research/raw/` 또는 `*.local.*` 파일에 둔다 → `.gitignore`로 커밋 제외.

## cases.csv 컬럼
- `출처유형`: 지식인 / 네이트판 / 더쿠 / 인스티즈 (EX-* 행은 예시라 `예시`)
- `쟁점`: 기존 ISSUES id(time, contact, money, chores, space, care, tone, team) 또는 `NEW:이름`
- `심각도`: 일상 / 주의 / 게임불가(폭력·스토킹·협박·자해 등 → 안전필터 대상)
