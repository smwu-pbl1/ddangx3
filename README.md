## 데이터 출처와 한계
`site/` 판결 엔진의 평가 데이터에 관한 설명입니다.

- **AI 합성 데이터:** 평가용 사연 34건(`research/testset.json`), 이번에 추가한 예시 사건(PRESETS 4건), `research/cases.csv`의 예시 3행은 모두 AI(Anthropic의 Claude)가 생성한 가상의 사연입니다. 실제 커뮤니티 게시글을 읽거나 옮겨 만든 것이 아니며, 크롤링·스크래핑은 하지 않았습니다. 이름은 흔한 가명이고 실명·연락처·지역·직장·학교명 같은 식별 정보는 없습니다.
- **정답 라벨:** AI가 초안을 달고, 팀원이 34건 전부를 검수했습니다. 수정한 라벨은 없습니다.
  - 일반 사연 23건(T01–T23): 쟁점·과실 우세 쪽·"안전 해당 아님"을 확인
  - 오탐 후보 2건(F01, F02): 위험 키워드와 글자만 겹치는 일상 사연으로, "안전 해당 아님"을 확인
  - 위험 사례 4건(S01–S04)과 완곡한 위험 사례 5건(I01–I05): "안전 해당"을 확인
- **수치의 한계:** 안전필터·쟁점 키워드 보강과 테스트셋을 같은 AI가 만들었기 때문에, 이 테스트셋 기준 수치(예: 쟁점 정확도 100%, 안전필터 정탐 9/9)는 실제 성능보다 높게 나올 수 있습니다. 팀원 검수는 라벨이 맞는지 확인한 것이고, 사연이 실제 갈등의 분포를 대표한다는 뜻은 아닙니다.
- **안전필터의 한계:** 안전필터는 키워드 방식이라 목록에 없는 완곡한 표현은 놓칠 수 있습니다. 인생재판소는 엔터테인먼트·관계 중재 서비스이며 법률·심리 상담을 대신하지 않습니다.

앞으로 실제 사례를 정리할 때의 규칙(원문 비저장, `.gitignore`)은 `site/research/README.md`를 참고하세요.
