## 데이터 출처와 익명화
`Week10_인생재판소_site/`의 판결 엔진 평가 데이터(`research/testset.json`)와 이번에 추가한 예시 사건(PRESETS)은 **AI(Anthropic의 Claude)가 생성한 합성 데이터**입니다. 실제 커뮤니티 게시글을 읽거나 옮겨 만든 것이 아니며, 크롤링·스크래핑은 하지 않았습니다. 이름은 흔한 가명이고 실명·연락처·지역·직장·학교명 같은 식별 정보는 넣지 않았습니다.

- 평가 라벨(쟁점·과실 우세 쪽·안전필터 해당 여부)도 현재는 AI 초안이며, 사람 검수 전입니다.
- 안전필터·쟁점 키워드 보강은 같은 합성 testset을 보고 골랐으므로, 그 testset 기준 수치는 실제 성능보다 높게 나올 수 있습니다.
- `research/cases.csv`는 앞으로 사람이 실제 사례를 수동으로 정리하기 위한 템플릿입니다. 원문은 저장하지 않고 유형·표현·재구성 요약만 기록하며, 원문 메모는 `.gitignore`로 커밋에서 제외합니다. 자세한 규칙은 `Week10_인생재판소_site/research/README.md`를 참고하세요.

인생재판소는 엔터테인먼트·관계 중재 서비스이며 법률·심리 상담을 대신하지 않습니다. 안전필터는 키워드 방식이라 완곡한 위험 표현을 놓칠 수 있습니다.
