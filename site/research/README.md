# research — 판결 엔진 평가

| 파일 | 내용 | 현재 상태 |
|---|---|---|
| `cases.csv` | 실제 갈등 사례 분석 표(유형·표현·심각도·재구성 요약) | **템플릿만 있음.** `EX-*` 3행은 AI 합성 예시이며 실제 사례가 아님 |
| `testset.json` | 엔진 평가용 사연 34건 + 판단 라벨 | **사연은 AI 합성.** 라벨은 AI 초안 → 팀원이 34건 전부 검수(수정 없음), `labeler: "human"` |
| `run_eval.js` | `node research/run_eval.js` — 쟁점 정확도·과실 일치율·안전필터 정탐/미탐/오탐. `--human-only`는 검수된 라벨만, `--judge=all`은 판사 4명 비교, `--base=<ref>`는 변경 전후 비교, `--presets`는 프리셋 회귀 | — |

## 데이터 출처와 한계
- **AI 합성 데이터:** 평가용 사연 34건(`research/testset.json`), 이번에 추가한 예시 사건(PRESETS 4건), `research/cases.csv`의 예시 3행은 모두 AI(Anthropic의 Claude)가 생성한 가상의 사연입니다. 실제 커뮤니티 게시글을 읽거나 옮겨 만든 것이 아니며, 크롤링·스크래핑은 하지 않았습니다. 이름은 흔한 가명이고 실명·연락처·지역·직장·학교명 같은 식별 정보는 없습니다.
- **정답 라벨:** AI가 초안을 달고, 팀원이 34건 전부를 검수했습니다. 수정한 라벨은 없습니다.
  - 일반 사연 23건(T01–T23): 쟁점·과실 우세 쪽·"안전 해당 아님"을 확인
  - 오탐 후보 2건(F01, F02): 위험 키워드와 글자만 겹치는 일상 사연으로, "안전 해당 아님"을 확인
  - 위험 사례 4건(S01–S04)과 완곡한 위험 사례 5건(I01–I05): "안전 해당"을 확인
- **수치의 한계:** 안전필터·쟁점 키워드 보강과 테스트셋을 같은 AI가 만들었기 때문에, 이 테스트셋 기준 수치(예: 쟁점 정확도 100%, 안전필터 정탐 9/9)는 실제 성능보다 높게 나올 수 있습니다. 팀원 검수는 라벨이 맞는지 확인한 것이고, 사연이 실제 갈등의 분포를 대표한다는 뜻은 아닙니다.
- **안전필터의 한계:** 안전필터는 키워드 방식이라 목록에 없는 완곡한 표현은 놓칠 수 있습니다. 인생재판소는 엔터테인먼트·관계 중재 서비스이며 법률·심리 상담을 대신하지 않습니다.
- 일반화 성능을 보려면 키워드 선정에 쓰지 않은 사연(가능하면 사람이 새로 쓴 것)으로 따로 측정해야 한다.

## 앞으로 사람이 실제 사례를 정리할 때의 규칙
- 크롤링·스크래핑 금지. 사람이 직접 읽고 **유형만 정리**한다.
- 원문 문장을 옮기지 않는다. `재구성 사연`은 일반화해 새로 쓴 1~2문장 요약.
- `자주 나온 표현`은 일반 구어 표현 단위(예: 안읽씹, 단톡방, 손절)만, `|`로 구분.
- 실명·닉네임·연락처·지역·직장·학교명·게시글 URL/제목 저장 금지.
- 원문을 보며 쓰는 개인 메모는 `research/raw/` 또는 `*.local.*` 파일에 둔다 → `.gitignore`로 커밋 제외.
- 실제 사례 기반 행은 `id`를 `EX-*`가 아닌 번호(예: `C001`)로 쓰고, `출처유형`에 지식인/네이트판/더쿠/인스티즈 중 하나를 적는다.

## cases.csv 컬럼
- `출처유형`: 지식인 / 네이트판 / 더쿠 / 인스티즈 (AI 예시 행은 `예시`)
- `쟁점`: 기존 ISSUES id(time, contact, money, chores, space, care, tone, team) 또는 `NEW:이름`
- `심각도`: 일상 / 주의 / 게임불가(폭력·스토킹·협박·자해 등 → 안전필터 대상)
